# 猫猫素材交付规格（ART-SPEC）

> 给做素材的人 / AI 生成工具看的。**只要按这里交付，我这边不需要改代码就能换上去。**

## 1. 需要哪些状态（4 个）

| 状态 id | 什么时候出现 | 播放方式 | 建议帧数 | 建议 fps | 参考时长 |
|---|---|---|---:|---:|---|
| `idle` | 专注计时中，右下角常驻 | 循环 | 8–12 | 6–8 | 1.2–2.0 s |
| `rise` | 专注到点，提醒弹窗出现时（弹窗内小图 + 宠物） | 循环 | 6–10 | 8 | 0.8–1.2 s |
| `drink` | 休息结束、喊你「回来干活」时 | 循环 | 8–12 | 8 | 1.0–1.5 s |
| `sleep` | 你点了【结束】、总结窗出现时 | 循环 | 6–8 | 4–6 | 1.5–2.0 s |

动作建议：`idle` 趴着呼吸起伏 + 偶尔眨眼；`rise` 起身伸懒腰；`drink` 抱杯小口喝；`sleep` 闭眼 + 头顶 zz 浮动。
**四个状态必须是同一个角色、同一比例、同一基线**（切换时才不跳）。

## 2. 画布与格式

**首选：透明 PNG 帧序列**

- 单帧画布：**正方形 512×512**（我装机时统一缩到 256×256，你按 512 做保证清晰度）
- 格式：**PNG-32，必须带 alpha 透明通道**（不是白底！）
- 构图：角色**水平居中**，四边各留 **≥24px 安全边**（512 画布上）；`idle`/`sleep` 的趴姿、`rise`/`drink` 的站姿，**身体底线放在同一个 y 坐标**
- 命名：`<状态>-NN.png`，NN 为两位序号从 01 开始（例：`idle-01.png` … `idle-10.png`）
- 目录结构：

```
cat-frames/
  idle/   idle-01.png … idle-10.png
  rise/   rise-01.png … rise-08.png
  drink/  drink-01.png … drink-10.png
  sleep/  sleep-01.png … sleep-07.png
```

**备选 A：单文件动图（最省事）**

- **动图 WebP（带 alpha）** 或 **GIF**，正方形 512×512，每状态一个文件：`idle.webp` / `rise.webp` / `drink.webp` / `sleep.webp`
- GIF 的透明只有 1 位、边缘会有锯齿；能出 WebP 就出 WebP

**备选 B：直接给视频，我来转（什么都不用管）**

- **MP4（H.264）或 WebM**，正方形 1:1，**≥512×512**，24–30fps，**每个状态 2–3 秒无缝循环**
- 背景用**纯色**：纯绿 `#00B140` 最好抠，洋红 `#FF00FF` 次之；**不要有阴影/渐变投到背景上**，角色边缘别被背景色污染
- 交付 4 个视频文件即可，我用 ffmpeg 抠像 → 抽帧 → 缩放 → 装进插件

## 3. 硬性禁止

- 不要白底/灰底"假装透明"（浮在聊天界面上会露出方块）
- 不要加投影到画布背景上、不要加边框、不要加水印
- 单帧不要放大到 1024 以上（体积涨得比清晰度快）
- 四个状态的**脸/兜帽/尾鳍**要一致：用同一张角色设定图 / 同一 seed 生成，再让模型只改姿态

## 4. 交付后我怎么换（供参考，你不用做）

1. 素材放进 `assets/frames/<状态>/`（或 `assets/anim/<状态>.webp`）；
2. 改 `assets/pet-manifest.json` 里对应状态的一行：
   ```json
   "idle": { "type": "frames", "dir": "frames/idle", "ext": "png", "count": 10, "fps": 8 }
   ```
   或单文件：
   ```json
   "idle": { "type": "file", "src": "anim/idle.webp" }
   ```
3. 刷新页面即生效（client 端每次加载都会读清单，缺清单/缺状态会回落到内置 SVG，不会白屏）。

## 5. 当前已装机的素材（2026-09-30 交接，供后续替换时对照）

| 状态 | 源帧 | fps | 装机形态 |
|---|---:|---:|---|
| idle | 10 张 512×512 PNG | 6 | `assets/anim/idle.webp`（动图 WebP） |
| rise | 8 张 | 8 | `assets/anim/rise.webp` |
| drink | 10 张 | 8 | `assets/anim/drink.webp` |
| sleep | 7 张 | 4 | `assets/anim/sleep.webp` |

装机流水线（脚本化，可重跑）：**统一基线**（按每状态全部帧的并集包围盒做一次整体平移，让内容**底边中点**落到 512 画布的 (256, 500)，同状态内不抖动）
→ **缩放**到 256×256（LANCZOS）→ **合并成动图 WebP**（quality 95、method 6、loop 0，单帧时长 = 1000/fps）。
体积：512 PNG 原图 11.4 MB → 装机后 4 个 WebP 合计约 **626 KB**（不透明区 RMSE 2.5/255，肉眼无差）。

## 6. 尺寸对照（免得做太大或太小）

| 出现位置 | 显示尺寸 | 你交付的 | 说明 |
|---|---:|---|---|
| 右下角常驻宠物 | 宽 104 px | 512×512 | 2.4× 余量，视网膜屏不糊 |
| 提醒/总结弹窗内的小图 | 宽 76 px | 同上 | 同一份素材复用 |
